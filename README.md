# GIMP & Python Automated Poster and Graphic Designer

A Python and GIMP Script-Fu toolkit for generating vector-quality recruitment posters, visual banners, and graphics programmatically.

## Features

- 🎨 **Pillow-Driven High-Res Poster Engine**: Custom gradient ramps, card containers, badge layouts, and typography grids.
- 🖼️ **GIMP Script-Fu Automation**: Procedural scripting templates for GIMP 2.10 / 3.0 batch mode.
- 📐 **Zero External Asset Dependencies**: Renders completely from code using system fonts and vector math.

## Usage

```bash
pip install -r requirements.txt
python create_poster.py
```

Generated output will be saved to `output/recruitment_poster.png`.
